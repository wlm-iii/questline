# Agent Instructions

Read and follow [CONTRIBUTING.md](CONTRIBUTING.md) before making changes to this repository. Its branch workflow, Conventional Commit requirements, review process, and quality standards apply to coding agents as well as human contributors.

- Work on an individual development or feature branch; do not commit directly to `main`.
- Keep changes focused on the requested task and follow existing project conventions.
- Run applicable checks and report their results, including checks that could not be run. Do not invent validation commands or claim unrun checks passed.
- Update relevant documentation when behavior, setup, or configuration changes.
- Do not merge into `main` without the required review approval.
